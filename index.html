Hermes Backup

Backups pessoais com criptografia local e armazenamento no Google Drive.

Como funciona

Hermes Backup é uma configuração pessoal de backup executada em um Raspberry Pi com rclone. O rclone crypt criptografa os arquivos localmente antes do envio para uma conta secundária do Google Drive controlada pelo proprietário. Na restauração, a descriptografia ocorre localmente.

Acesso limitado

A integração OAuth usa o escopo drive.file, destinado a arquivos criados pelo aplicativo ou explicitamente disponibilizados a ele. Não solicita acesso geral a todos os arquivos do Drive. Este projeto não oferece cadastro público nem um serviço comercial.

Privacidade e contato

Não vendemos dados nem usamos os arquivos para publicidade. Consulte nossa Política de Privacidade.

Contato: perfil thiago-it no GitHub. Não publique dados pessoais, arquivos, credenciais ou chaves ao entrar em contato.
